In the Generator
1

Fill in their info

Open generator.html. Click New Person if you were editing someone else. Fill in Identity, Phone, Email — click Add more details for anything else.

2

Preview it

Click Preview and check the actual card before saving anything — much faster than catching a mistake after it's live.

3

Copy the Tag URL & Save

Copy the Tag URL field — it already includes this person's unique security token. Click Save or Download data.json.

On Your Computer
4

Create the folder

Name it exactly like the generator's Folder Name field — lowercase, hyphens not spaces (e.g. sam-lee).

5

Copy in the template

Copy person-template/index.html into the new folder unedited — never property-template/index.html, and never a copy from another person's folder.

6

Add data.json & photo

Place the downloaded data.json inside, plus a photo named to match the photoFile field (default photo.jpg).

Publish It
7

git add & commit

In Git Bash, from your project folder: git add . then git commit -m "add sam".

8

git push

Run git push. Vercel notices the new commit and redeploys automatically — no dashboard clicks needed.

9

Test the live page

Visit blackhatcards.community/sam-lee/ (trailing slash matters) on your phone. Confirm the photo, buttons, and Save to Contacts all work.

Write the Tag
10

Write the Tag URL — not the plain link

Open NFC Tools → Write → Add a record → URL. Paste the exact Tag URL you copied in Step 3 — it includes ?t= plus this person's token. The plain folder link (without the token) will never appear as "Verified" on any future update request, so don't hand that one out. Hold a blank tag to write it, then tap it once more yourself to confirm it opens the right page before locking.

Reminders

  • Folder and file names must stay all lowercase — Index.html or Jane-Doe will 404
  • Always copy person-template/index.html fresh — never reuse another person's folder as a starting point; it may be out of date
  • The Tag URL (with the token) is what goes on the physical tag. The plain link is what you'd type by hand — never text or email that one to the person themselves
  • Don't lock the tag until you've tapped it yourself and confirmed the page loads correctly
  • A photo needs to already be sitting inside that person's own folder — not linked from anywhere else
