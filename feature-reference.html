Every Feature, By Tool

A reminder of what's actually possible — see MANUAL.md for step-by-step instructions on any of these

Every Card, Always
Save to Contacts — one-tap vCard download
Share Your Info — visitor sends you theirs, Text or Email
Save as PDF — the full card as a printable page
Print QR Code Only — minimal name/address + QR printout
Contact / Support / Updates — self-edit link, pre-fills the intake form
generator.html — Person Cards
Brand field — apply a business or personal color palette
Gallery — up to 10 photos with captions, reorderable, opens in an in-page viewer
Listings — link up to 5 property cards from your own card
Websites — multiple, reorderable, shows "View Site" not a raw URL
Social — malformed input is skipped, never publishes a dead link
Collect Info — QR for crowds or NFC-disabled phones
Scan a Card — OCR a business card, review before sending to yourself
Refer a Friend — shares the intake form link directly
Move ↑↓ buttons — reorder any repeatable field: phones, emails, websites, listings, experience, gallery
Load / Save / Download — edit an existing person's file directly
property-generator.html — Listings
Photo gallery — any number of photos, no cap
Agent card — auto-initials avatar if no agent photo given
Schedule a Showing — a real booking link
Link to Another Listing — cross-reference a second property
Brand field — same mechanism as person cards
Print QR Code Only — side-by-side QR + address, built for a flyer or yard sign
brand-generator.html
Accent color — auto-generates a matching soft/hover variant
Background color (optional) — auto text-contrast, auto panel shading, safe for any color
Live preview — the real colors, fetched live — not a simulation
Reset to Defaults — one click back to the starting palette
Load Brand File — edit an existing business or personal brand
biz- / solo- naming — team brand vs. one person's own variety, at a glance
bulk-generator.html
CSV import — many new person folders written at once
Never overwrites — skips any folder that already exists
Intake Forms
Landing choice screen — "see how it works" vs. "I'm ready," before any field is asked
Text It / Email It — a genuine fallback if one method doesn't work on their phone
"You're All Set!" panel — immediate confirmation, not a wait for your reply
Auto-skip on edit — the landing screen never shows when opened via an existing person's edit link
