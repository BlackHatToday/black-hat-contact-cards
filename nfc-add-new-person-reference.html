Adding a New Person

Folder → GitHub → Vercel → NFC tag, for each new friend you add

New folder
→
Edit index.html
→
git push
→
Vercel auto-deploys
→
Write tag
On your computer
1

Create a new subfolder

Inside your project folder, add one new folder named after the person — lowercase, hyphens not spaces (e.g. sam-lee).

2

Copy in the template

Copy your existing index.html from any finished folder into the new one, keeping the filename lowercase.

3

Edit CARD_DATA

Open it, update name, phone, email, org, and photoUrl in the CARD_DATA block. Save.

Publish it
4

git add & commit

In Git Bash, from your project folder: git add . then git commit -m "add sam".

5

git push

Run git push. Vercel notices the new commit and redeploys automatically — no dashboard clicks needed.

6

Test the live page

Visit yourproject.vercel.app/sam-lee on your phone. Confirm photo, animation, and Save Contact button work.

Write the tag
7

Write the URL record

Open NFC Tools → Write → Add a record → URL (not vCard, since this is a link this time). Paste the person's live page URL, e.g. yourproject.vercel.app/sam-lee. Hold a blank tag to your phone to write, then tap it once more to confirm it opens the right page.

Reminders

  • Folder and file names must stay all lowercase — Index.html or Jane-Doe will 404
  • Don't lock the tag until you've tapped it yourself and confirmed the page loads correctly
  • A photo needs to already be hosted somewhere — pushing it into an images folder in the same repo works well
