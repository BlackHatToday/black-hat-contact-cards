Before you push — the one thing that bites most often

Every file above must sit at your project's root, exactly one level above every person/property folder — never nested inside one.

Existing person/property folders already pushed do not automatically pick up template or style changes — only new folders get the current version. If you want an existing card to reflect today's changes (Refer button, moved sections, branding), its index.html needs to be manually replaced with the current template.

brand-generator.html and bulk-generator.html work differently from the rest — both write directly to your local files via a folder picker (Chrome/Edge only), rather than downloading something to move yourself. bulk-generator.html specifically will never overwrite an existing person folder — it skips and logs it instead.
