Start — Pick One
1

Creating a brand nobody's used before

Open brand-generator.html. Type the name — the slug auto-fills. Prefix it yourself: biz- for an actual business or team, solo- for one person's own personal variety with no business behind it.

1

Updating a brand that already exists

Same page. Click Load Brand File and pick the existing brands/{slug}.json you want to change. Every field fills in with its current colors.

Accent color

Every button, icon, and highlight across the card. The hover/soft variant auto-generates — override it yourself for a specific shade.

Save or Download

Writes to brands/{slug}.json at your project root — filename includes the biz-/solo- prefix.

Attach It — the Step It's Easy to Forget
6

Creating the file alone changes nothing yet

Open generator.html for a person, or property-generator.html for a listing. Load their existing data.json, type the brand's full slug — prefix included — into the Brand field, then Save. Click Preview first if you want to see it before committing; it fetches the real colors, so what you see is what goes live.

Reminders

  • One brand file can be attached to any number of people or listings, or just one — nothing distinguishes a shared team brand from a single person's own personal variety except which prefix you gave it
  • Rebranding later is just Load Brand File → adjust → Save — everyone referencing that slug updates automatically, no per-card edits
  • A brand change never touches a physical NFC tag — colors are fetched fresh on every tap, never baked into the tag or its token
  • Both generators' own Preview button fetches the real brand colors before showing the card — if Preview looks wrong, the live card will too
